## 效果示例

一位妈妈半夜来，说初三的女儿回家就抱着手机，说了多少遍都不听。

```
家长  ❯ 她每天回家就玩手机，作业拖到十一点，说了多少遍都没用

不烧心 ❯ 你说了多少遍，这件事就已经变成你的事了。
         她现在的任务不是写作业，是扛住你。扛住妈妈比开始写作业容易太多。

         所以今晚别谈手机。就一句：「八点开始写。」说完你走开。
         不在旁边站着，不看她，不叹气。

         站着就是监工。监工能让所有工作变成对抗。
```

另一位妈妈，同样是手机。但这次多问了三句。

```
家长  ❯ 我女儿也是天天玩手机到半夜，我该怎么办

不烧心 ❯ 先别管手机。我问你三件事：
         她几点躺下、几点才睡着？
         最近有没有哪个人跟她闹掰了？
         这两个月她瘦了吗？

家长  ❯ 十一点躺下，两三点才睡。上个月跟她最好的朋友闹翻了。瘦了。

不烧心 ❯ 那手机不是瘾，是止痛药。
         一个孩子躺在床上睁着眼睛三个小时，她不是在玩，她是在想办法让自己不想那件事。
         现在收她手机，等于把她唯一能睡着的方式也拿走了。

         今晚什么都别做。明天先跟她聊那个朋友，不聊手机。
```

第三位家长，初二男孩，一周六个晚上都在补课，成绩还是往下掉。

```
家长  ❯ 数学物理英语都补了，一周六个晚上，成绩反而掉了

不烧心 ❯ 不是补得不够，是补得太多。
         一周六晚、七门课，等于他每天被证明七次「我不行」。

         这个年纪的孩子，你让他连续失败两个月，他学会的不是知识，是「我学不会」。
         一旦这条成立了，你再加三门课也没用。

         这周先砍掉两门。留下他自己觉得最不讨厌的那一门。
         剩下的时间不安排任何学习——不是奖励，是止损。
```

这不是话术。**第一段用的是「责任转移」，第二段用的是「先分清是瘾还是止痛药」，第三段用的是「失败密度」。** 每一句背后都对应一个判断，判断错了，动作就是反的。

## 它到底怎么不一样

| | 一般的育儿 AI | 育儿不烧心圣经 |
|---|---|---|
| **第一次见面** | 立刻给你 3 条建议 | **一条都不给，只问**。差一点情况，答案就完全相反 |
| **它站谁** | 中立客观，两边都有道理 | **只站家长**。不替学校说话，不替专家说话，不给模棱两可的选项 |
| **它给什么** | 原则、心态、沟通技巧 | **能变成今晚一个身体动作的句子**。「多陪伴」不是动作 |
| **它记得吗** | 每次都从零开始 | **建档、写预判、下次先问你上次那条做了没** |
| **什么时候认怂** | 不知道也说一堆 | 四种情况直接叫你去医院，其余全部给方案 |
| **危险信号** | 照常给建议 | **红旗先于方案**。有自伤、有失联、有功能断崖，方案全部让位 |

一句话：**别的工具在教你怎么当父母，它在替你把这一仗打下来。**

## 它给了你什么

市面上不缺育儿知识。缺的是**在你家这个具体条件下、今晚这一步该迈哪只脚**。所以它给的不是知识，是六样东西：

| 层 | 说明 |
|---|---|
| **这是什么情况** | 一句话定性，说到你没说出口的那层 |
| **先明白一个道理** | 一条原理，能解释「你之前的做法为什么不行」 |
| **你现在就能做的** | 2–3 个动作，标明哪个先做。**必须能变成今晚一个身体动作** |
| **要多久 · 中间会怎样** | 第 1–2 周会怎样、第 3–4 周该出现什么信号、第 5–8 周进下一步 |
| **终点在哪** | 你要的是 A，这条路先到 B，A 和 B 是什么关系。**不美化** |
| **该谁做 / 别做 / 何时换方法** | 哪几条该交给老师或机构、哪几个动作会让事情更糟、什么信号说明这套不管用 |

### 「要多久」这一栏，比方案本身还值钱

家长的心理崩溃点通常在**第 3–7 天**——动作做了，孩子没反应，于是怀疑「是不是没用」，然后回到老路。

所以它提前告诉你「前两周可能一点变化都没有，甚至更糟」，还告诉你为什么会这样。**这一句话是拿来撑过第 5 天的。**

同时它会帮你分清两种「变化」：

- **看得见的变化**（分数、排名）→ 慢，半年起
- **先发生的变化**（状态、意愿、某个具体动作）→ 快，2–4 周

**盯后者。** 家长之所以三周就放弃，是因为一直盯着分数。

### 诚实边界

每个判断都标了它在什么情况下不成立。**一个不告诉你局限在哪的专家，不值得信。**

- **不给结论式承诺。** 目标是「让情况不再恶化」，不是「让他马上变好」。承诺改变的育儿方法都在骗人
- **不替你做重大决定。** 离婚、转学、要不要二胎，它只帮你看清每个选择的代价
- **不碰诊断和用药。** 涉及自伤、自杀、持续情绪低落、注意力与发育问题，一律当天去医院，并且告诉你挂哪个科
- **不用话术操控孩子。** 目标是让对话能继续、让真实状态浮现，不是让他听话
- **它的知识边界是公开的。** 内部素材只用来说话像人，不作对外依据——你问它「这话谁说的」，它只会给三种来源：研究结论（大学/机构）、权威著作（书名+作者）、学科共识。记不清就说「有一项追踪多年的研究」，**宁可模糊，不可编造**

```
references/          intake-guide.md      首次对话纯采集协议（一条建议都不许给）
                     principles.md        原理库 10 条（一次只讲一条）
                     data-schema.md       七张表字段定义
                     professional-handoff.md  什么该交给机构和老师

                     scenarios-common.md  高频场景详写

  scenes.json                            10 簇分类骨架（公开版不带家长原话）
  memory/records/_schema.json            七表空模板
  memory/records/_index.json             空索引（装好后第一次对话会自动建）
  memory/sessions/_template.md           会话流水模板
```

**七张表**指的是：`children` / `household` / `presenting_problem` / `attempts` / `parent` / `sessions` / `redlines`。

其中三张是整个飞轮的关键：

- **`attempts`** 记录你试过什么、哪个完全没用 → 它**不会重复推荐已经失败过的方法**
- **`parent.sustainability_days`** 记录你实际能坚持多少天 → **方案周期永远不超过这个数**
- **`sessions.prediction`** 是轴心 → 每次给完方案必须写预判，下次才能验证方向对不对

## 工作原理

### 第一次见面：只号脉，不开方

这是整套东西最反直觉的一条，也是它的分水岭。

**首次对话禁止输出任何答案、分析、判断或方案。** 包括「你可以先试试」、包括「这可能是三种情况之一」、包括「你别急，很多家庭都这样」。

因为第一次什么都不知道，任何判断都是猜——但家长听起来像建议。**通用话术最容易在这个位置冒充专业判断。** 而且一旦开了口，他会以为「就这样了」，你后面再问细节，他觉得你在补作业。

所以它只做一件事：给出五组采集清单，让他一次说完。

| 组 | 问什么 | 为什么 |
|---|---|---|
| 一、孩子本人 | 年龄年级、性格偏向、睡眠与身体 | 决定这条路的坡有多陡 |
| 二、家里谁在带 | 主责人、夫妻是否一致、有没有老人 | **决定方案能不能落地**。有老人护着、配偶拆台，很多方法根本执行不了 |
| 三、具体是什么事 | 最痛的一件、最近一次的原话、**突然还是一直** | 「突然」= 有触发事件要查；「一直」= 是模式要改结构。**两个世界** |
| 四、试过什么 | 哪个稍微有点用、哪个完全没用 | 不问就会重复推荐，他会觉得你根本不懂他家 |
| 五、家长自己 | 最怕什么、每天能拿出多少时间 | **决定方案的份量**。每天加班到九点的家长，给不了需要固定半小时的方案 |

采集完先复述一遍请他确认——**这一步是信任的分水岭。**

### 之后每次：红旗先于方案

四种情况直接去医院，其余全部给方案，并且说清挂哪个科：

1. 提到自伤、自杀、不想活 → 当天精神科或心理科
2. 持续两周以上的情绪低落 + 睡眠食欲改变 + 拒绝上学 → 儿童心理科评估
3. 怀疑注意力障碍、学习障碍、发育问题 → 儿童保健科或发育行为科
4. 家长自己已经撑不住 → 家长自己也需要看

**「建议咨询专业人士」这句话只有这四种场合可以说，其余场合说了就是推卸。**

### 输出：一条路，不是三个建议

只给动作是半成品。家长要的不只是「做什么」，还有「做多久」「中间会怎样」「最后能不能到我想去的地方」。缺了后三样，他执行到第三天就开始怀疑，第七天就放弃。

还有一条顺序，绝大多数家长是跳过的：

```
先修关系 → 再处理情绪 → 最后才谈具体问题
```

**跳过前两步直接谈问题，就是「话都对、他都不听」的原因。**

### 飞轮：越用越懂这个家

```
第 N 次：给方案 + 写下预判 + 请他反馈
   ↓
第 N+1 次：「上次那条你做了吗？后来发生了什么？告诉我，我记下来」
   ↓
   做了有效 → 往「事前」那层推进
   做了没用 → 换方案，绝不重复推荐
   没做     → 降难度（不是没决心，是那步太难）
   ↓
第 N+2 次：起点比第一次高
```

所有记忆**只存在本地**，用代称，不写真名校名。家长说「别记这个」就不记。

## 背后的故事

我做了十几年一线家庭教育，见过几千个家庭的崩溃现场。

真正让我受不了的不是家长不会教——**是他们被夹在中间，四面都有人讲道理。**

老师说「你们家长要配合」，机构说「别去看心理医生」，奶奶说「孩子就是惯的」，专家说「要多共情、要温柔而坚定」。每一句都对，每一句都不解决今晚这顿饭怎么吃完。

而家长真正在半夜里想的是：**那我呢？我该做什么？**

所以这个 skill 的第一条立场就是：**永远站在家长这一边。** 不替机构说话，不给「两边都有道理」的平衡，他能做的事给明确做法，不说「你可以考虑一下」。

他做错了，直说，但说的时候必须带补救办法——**指出问题是为了帮他，不是为了显得我公正。**

唯一的底线是：他的诉求会伤到孩子本身（掩盖虐待、逃避必要医疗、延误治疗），明确拒绝并说明原因。除此之外，一律站他。

**它护的是你，不是你的错。**
