# 来源与引用规范

这份文件约束本仓库所有内容怎么写、什么不能写。**违反它的内容不予合并，包括作者自己的。**

---

## 一、总原则

本仓库做的是**对照分析**，不是**内容汇编**。这两者在法律上的地位完全不同：

| | 对照分析 | 内容汇编 |
|---|---|---|
| 形态 | 提出一条分歧线，说明各派立场，给出证据判断 | 把若干本书的要点整理归类 |
| 原创成分 | 高（分歧线的划分、证据比较、适用条件判断都是原创劳动） | 低（只是搬运与排序） |
| 法律地位 | 独立作品 | 可能是演绎作品，须获授权 |
| 本仓库 | ✅ 唯一允许的形态 | ❌ 不接受 |

**判断标准很简单**：删掉所有具体书目，这份文件还成立吗？
- 还成立 → 你写的是分析，可以。
- 就不成立了 → 你写的是汇编，不行。

---

## 二、允许

- 描述一个流派的**核心假设、历史地位、被取代的过程**——属公开学术史。
- 陈述**公开学术共识**（如"体罚的有害性在研究中高度一致"）。
- 说明某本书**属于哪一派**，以及**该派存在什么分歧**。
- 用**你自己的话**概括一个立场。
- 使用**自造案例**或你自己的一线经验作例证。
- 直接引用**极短的术语**（如"安全基地""自然后果"），这些是学科通用词。

## 三、禁止

- ❌ 复制原文，哪怕一句。要表达同一个意思就重写。
- ❌ 复述书中**独家案例**。案例是最容易被认定为"表达"的部分。
- ❌ 照搬**章节结构**。书的组织方式是作者的创造性劳动。
- ❌ 使用书中**独创的专有框架名称**并加以展开描述（可以提及"该派提出了 X 框架"，但不展开复刻其内部结构）。
- ❌ 给出"第 X 页写道『……』"式的原文引证。
- ❌ 大段翻译外文原著——翻译本身产生新的著作权。
- ❌ 把多本书的内容拼成一份"完整方法论"，那是最典型的汇编。

## 四、引用格式

内部核对时（不对公众展示）可记录到页：

```
《书名》作者，版本，第 X 页 —— 用于核对，不外发
```

公开文件中一律写成：

```
该派的核心主张是……（相关论述见 books.md 所列著作）
```

**能给"属于哪一派"，不给"原文怎么说"。**

## 五、证据强度怎么标

每条主张必须标一档，标签本身也要能自我解释：

| 标签 | 含义 | 写法要求 |
|---|---|---|
| **高** | 有较多纵向研究或元分析支持，跨文化验证较充分 | 可以写"证据较为一致" |
| **中** | 特定条件下有研究支持，迁移到家庭日常存在损耗 | 必须写出"在什么条件下" |
| **低** | 主要靠实践反馈或临床观察，缺乏严格对照 | 必须写"实践反馈多，对照研究少" |
| **分裂** | 不同研究结论不一致，效应大小依赖条件 | 必须写清"分歧在哪个变量上" |
| **无支持** | 流行但检索不到支持性证据 | 写"目前没有证据支持"，不写"已被证明错误" |

**禁止**：使用"科学证明""研究表明"这类无指向的权威化措辞。要么写清是什么类型的研究，要么写"据该派实践者观察"。

## 六、必须写边界

**任何方法、主张、流派描述，都必须附上"它在什么情况下不管用"。**

写不出边界的，视为调研不完整，不予采纳。这条不是风格要求，是本项目的立身之本——一个不说自己局限在哪的东西，不值得信任。

对照示例：

- ❌ "依恋理论认为及时回应建立安全感。"（无边界）
- ✅ "依恋理论认为及时回应建立安全感；但该框架解释力强于操作力，它说明'要敏感响应'，不说明具体这句话怎么接。"（有边界）

## 七、核实流程

```
候选书目 → 读原文 → 填 books.md「逐本核实记录」→ 通过六问过滤器
   → 提取可写入的主张（自己的话）→ 标注证据档位与边界 → 写入 SKILL.md
```

**未填核实记录的书，其任何主张不得进入 SKILL.md。** 这一条对作者本人同样有效——不能因为"我记得书里是这么说的"就写进去。记忆会错，尤其是隔了几年之后的记忆。

---

## 八、侵权处理

如权利人认为本仓库内容侵权：

1. 提 issue，说明涉及的具体书名与段落。
2. 我们会在 3 日内核对。
3. 确认存在问题的内容，立即删除或重写，并在 README 的变更记录里注明。

**不争辩，先处理。** 这个仓库的价值在分析方法，不在任何一本书的内容，删掉没有损失。
