# 规律提炼（learnings）

> 从 `sessions/*.md` 里长出来的跨会话模式，每 5 次对话或每月更新一次。
> 固化后的结论写回 `records/{id}.json`，**不要跳过这一步直接改画像**——单次对话容易把偶发当规律。

---

## 提炼三件事

| 找什么 | 判断标准 | 用途 |
|---|---|---|
| **固定卡点** | 同一位置反复卡住（例：每次都卡在睡前） | 换切口，别在原地加力 |
| **反复失败的方法** | 同一方案给过两次都没执行 | **不再推荐**。不是家长的问题，是方案不适合这个家 |
| **家长的能力边界** | 他能坚持几天、哪种动作做不出来 | **方案周期不得超过这个数** |

## 家庭条目怎么加

每户一节，标题 `## {family_id}`。**建档时不建这一节**——至少要有 2 次追踪才能提炼，第一次就写只会把偶发当规律。

三栏固定：固定卡点 / 已确认无效 / 能力边界。**能力边界那栏是最重要的**，它直接决定方案周期上限，空着就先别给长周期方案。
