# 常见场景补充

全部八个详写场景都在这里（主文件只留索引）。**Q03 / Q04 / Q05 / Q07 / Q08 / Q09 / Q10 这七簇没有详写场景**——命中它们时不要翻这里，直接走第 3 层学科共识判断。

格式与主文件一致，省略"如果已经搞砸了"一节——通用做法是：当晚不加码，第二天平静地认你那一半，不要求他认他的那一半。

### 场景一｜玩游戏／刷视频，作业不动

**【这是什么情况】** 不是他管不住自己，是**这件事已经变成你和他的事了**。他对抗的不是作业，是你的催促——因为"扛住妈妈"比"开始写作业"容易太多。

**【你现在就能做的】**
① **只说一次，然后离开。**「八点开始写。」说完去做你的事，不在旁边站着、不看他、不叹气。**站在旁边就是监工，监工会让所有工作都变成对抗。**
② **把后果还给他。**不提醒第二次、不代写、不帮他跟老师解释。明天被点名，那是他的事——你唯一不能做的就是替他挡这一下。
③ **改环境，不改他。**设备放公共区域、约定"作业前不碰"。这些是你控制的；"让他自觉"不是。

**【这几件事别做】**
- 坐在旁边陪写 → 会变成"你不坐下他就不动"，你从此被绑定
- 关掉游戏那一刻讲道理 → 情绪高点的道理只会被当成攻击
- 用"写完就给你玩手机"交换 → 你在训练他"作业是换奖励的苦役"，价码以后只会涨

**【根子在哪】** 规则要在周末下午定，不在冲突当晚定。说清三件事：几点开始、做完才能做什么、没做的后果。**只说你做得到的后果**（"没写完明天你自己跟老师说"），不说你做不到的（"以后再也不许玩游戏"）。

**【什么时候需要换方法】** 如果三周后依然是"不催不动"，说明他不是时间管理问题，是**这件事对他没有任何意义**。那时候要谈的不是时间表，是他到底想成为什么样的人——这个得另开一次对话，不能在气头上谈。

### 场景二｜放学回家只想看电视／躺着

**【这是什么情况】** 先排除一个误判——**放学后需要缓冲是真的需求，不是懒**。在学校坐八九小时、被规则压一天，回家第一件事就是卸压。这时逼他立刻进入第二场，反抗是生理性的，不是态度问题。

真正的问题不是"他一回家就看电视"，是**缓冲没有边界，会一直滑到睡觉**。

**【你现在就能做的】**
① **给缓冲一个明确长度，不是取消缓冲。**「六点到六点半你可以先缓一下，六点半我们开始。」承认他需要缓冲，但给它边界。
② **用一个"启动动作"代替命令。**不说"去写作业"，说「六点半我把桌上东西收一下」。启动身体动作，比启动任务容易得多。多数卡住的孩子不是不想写，是不知道从哪一下开始。
③ **他自己选了时间，就让他守。**如果六点半不动，不再提醒，直接说明后果：「说好六点半，现在六点四十了。今晚作业时间少十分钟。」**然后不再说话。**

**【这几件事别做】**
- 把"想看电视"定义为堕落 → 这个标签会让他觉得在你眼里就是懒的，那就真懒给你看
- 一边同意"缓一下"，一边每五分钟看一眼表、叹一口气 → **这比直接骂更有效，也更伤人**
- 让规则由你的情绪执行 → 今天心情好就放过，明天心情差就发火，他会学到"规则取决于妈妈今天好不好"

**【根子在哪】** 在他还没回家的白天，把规则定好，并**让他参与定**：几点到几点缓冲、缓冲做什么、之后怎么开始。参与过的人，遵守率完全不同。

**【什么时候需要换方法】** 如果他连"缓一下"都在刷手机而不是放松，说明屏幕本身就是问题，不是时间安排问题。这时候要处理的是设备位置，不是作息表。

## 场景三｜作业开始了，但磨蹭拖拉

**注意与场景一的区别**：场景一是"不开始"，这里是"开始了但极慢"。处置完全不同。

**场景本质**
磨蹭几乎从不是懒。常见两种，先要分清：
- **卡点型**：某一步不会，用磨蹭掩盖。特征是磨蹭集中在某一科或某一类题
- **启动型**：注意力被切碎，每次回来都要重新启动。特征是写两分钟就摸东西、喝水、上厕所

**分辨方法**：问他一句「哪道题卡住了？」。他能指出具体题目 → 卡点型；他说"没有啊"然后继续慢 → 启动型。

**你一直在做的，为什么没用**
- **坐在旁边盯着** → 压力升高，速度更慢。被盯着做事，成人的效率都会掉三成
- **每错一题就指出来** → 你在不断打断他，等于帮他练习分心
- **说"专心点"** → 这是一句无法执行的话，他自己也不知道怎么"专"

**此刻你做的三件事**
1. **卡点型：先花五分钟帮他拆那一道题。** 只拆这一道，不讲课、不扩展到同类题。拆完就走。
2. **启动型：把作业切成 15 分钟一段，每段之间休息 5 分钟。** 用计时器，不用嘴。计时器是规则，你的嘴是催促。
3. **离开房间。** 约定「我 20 分钟后进来一次」，然后真的只进来一次。**你在房间里待着，他就在为你看而写。**

**此刻你不能做的**
- 不能在旁边刷手机——你在示范"一边做事一边摸鱼"
- 不要在他写完一科时说「这科写完啦？那数学也顺便做了吧」——**这是毁掉所有提速努力的最快方式**
- 不要说「你怎么这么慢」——他会把它听成"我是个慢的人"，然后照做

**根在事前**
写作业前用两分钟过一遍：今天有几项、先做哪个。**启动摩擦最大的不是写，是"决定先写哪个"。** 这两分钟能省掉半小时的磨蹭。

## 场景四｜早上赖床，上学要迟到

**场景本质**
他的身体确实没醒，但**"不迟到"这件事目前是你在负责，不是他在负责**。你越是确保他不迟到，他就越不需要自己起来。

而且早晨是一天里时间最紧、家长耐心最少的时段，冲突成本最高——所以这里的规则必须简单到不需要思考。

**你一直在做的，为什么没用**
- **连叫五遍** → 你在训练他"前四遍可以不理"。第五遍才是真信号
- **掀被子** → 身体攻击。他记住的是被侵犯，不是该起床
- **「我走了啊」** → 你做不到。说一次贬值一次，说三次以后这句话等于没有
- **最后帮他穿衣服** → 他在这一刻学会：只要拖得够久，事情会有人替他做完

**此刻你做的三件事**
1. **只叫一次，说清时间和后果。**「六点四十了，七点出门。」然后你去洗漱，不再进他房间。
2. **把闹钟交给他。**前一晚让他自己定，自己按掉。**责任转移必须有一个实物载体**，闹钟就是这个载体。
3. **迟到就让他迟到。**不催、不替他跟老师请假、不在车上骂。让他自己去面对那一次。**你唯一要忍的，就是这一次。**

**此刻你不能做的**
- 不要在车上骂——一天的基调就定了，他到学校是带着羞辱去的，那一整天都学不进去
- 不要用"迟到会被老师罚"反复吓他——他知道，你反复说只会让他觉得你在享受这件事
- 不要一边说"以后你自己负责"，一边第二天又开始叫五遍。**反复横跳比一直催更糟**

**根在事前**
晚上把书包、要穿的衣服、要带的东西全部放在门口。**早晨所有的摩擦，基本都是前一晚没做的事。** 这一条比任何叫醒技巧都管用。

## 场景五｜房间乱，东西不收

**场景本质**
这不是卫生问题，是**控制权问题**。房间是他唯一完全属于自己的地盘。你越进去收拾，他越不在乎——因为"收拾房间"已经从"他的责任"变成了"你的项目"。

**你一直在做的，为什么没用**
- **一边骂一边替他收** → 最坏的组合。他既不需要负责，还要听你骂。他学到的是"忍着就好，反正最后有人收"
- **要求"有条理"** → 无法执行的标准。什么算有条理，你们的标准不一样
- **突击检查、当场发火** → 把收纳变成了执法

**此刻你做的三件事**
1. **把标准降到一条线。** 比如「地上不能有吃的东西」。一条能执行的底线，胜过十条做不到的要求。
2. **划清地盘。** 公共区域（客厅、饭桌）你管，他的房间他自己管。**你不再进他房间收拾**，除非他开口请你。
3. **提供条件，不提供要求。** 他缺的常常不是意愿，是收纳空间——给他买箱子、挂钩、架子，比说"你要有条理"有用得多。

**此刻你不能做的**
- 不要把他的乱和"你这个人怎么样"挂钩（"这么邋遢以后怎么办"）
- 不要在亲戚面前拿这个当笑话讲
- 不要定一个你自己都守不住的规定（"这周必须全部整理完"）

**根在事前**
一条底线 + 收纳条件 + 明确的地盘划分。三样齐了，多数冲突会自然消失——**因为他终于有一块不需要跟你争的地方。**

## 场景六｜吃饭看手机、挑食

**场景本质**
吃饭是少数**你完全无法强迫**的事。他只要闭着嘴，你没有任何办法。所以餐桌上所有的战争，赢的都是孩子。

明白这一点，就不会再在饭桌上使劲。

**你一直在做的，为什么没用**
- **"再吃三口"** → 把吃饭变成交易。三口之后还有三口
- **单独给他做第二份** → 他确认了"不吃正餐也能吃到想吃的"
- **饭桌上谈成绩、谈批评** → 他把"吃饭"和"被审判"绑定，从此不想上桌

**此刻你做的三件事**
1. **规则定在开饭前，不说在饭桌上。**「吃饭的时候手机放客厅，包括我的。」**你自己先放**，这一条才有分量。
2. **不追、不劝、不做第二份。** 吃完就收，不评价他吃了多少。
3. **下一顿之前不给零食。** 这是唯一能让"不吃"产生后果的方式。**但你得真的忍得住**——忍不住就前功尽弃。

**此刻你不能做的**
- 不要在饭桌上翻旧账。餐桌一旦变成法庭，他就永久性地不想来了
- 不要用"你不吃我就伤心"——用情绪绑架换来的进食，代价比挑食大得多
- 不要当着他的面跟别人说"我家这个特别挑"——你在给他发身份

**根在事前**
家庭餐桌规则 + 零食管理。**挑食的根通常在零食，不在餐桌。** 先看两餐之间他吃了什么，再谈桌上那盘菜。

## 场景七｜兄弟姐妹抢东西、打架

**场景本质**
他们要的往往不是那个东西，**是你的裁决**。你一旦开始当法官，就会永远被叫去当法官——而且无论怎么判，总有一个觉得你偏心。

**你一直在做的，为什么没用**
- **判对错** → 你不在场的时候，他们没有任何解决能力，只会打得更凶
- **「你是哥哥，让着点」** → 最容易埋雷的一句。它同时教会两件事：大的活该吃亏，小的可以靠示弱拿到东西
- **各打五十大板** → 公平感最差的一种处理，两个人都觉得委屈

**此刻你做的三件事**
1. **先分开，不判对错。** 把人和东西分开，一句「先都停一下」。不安慰、不问谁先动手。
2. **让他们各自说，你只复述。**「他说你先抢的，他说是你先拿的。」**只复述，不加评论、不表态。** 被准确复述这件事本身，能让情绪降下来。
3. **把方案交回给他们。**「这个玩具你们商量一个办法，商量好了来告诉我。」然后你真的走开。

**此刻你不能做的**
- 不要当裁判。你判得再公平，也总有一个不服，而且他会认定你偏心
- 不要要求大的无条件让——这条规则的长期代价，是兄弟关系本身
- 不要事后偷偷补偿某一方。孩子对"暗中偏心"的敏感度远高于明面上的

**根在事前**
物权规则 + 私有物。"这个是你的，他不问过你不能拿"——**先把"什么是我的"划清楚，抢的行为自然少一半。**

## 场景八｜考试考砸了

**场景本质**
他比你更清楚自己考砸了，这件事不需要你通知。他此刻要的不是分析，是**确认自己还有救**。

这时候讲道理、做复盘，收到的效果几乎一定是反的——因为他听到的是"你不行，而且你不努力"。

**你一直在做的，为什么没用**
- **当晚逐题复盘** → 在情绪最低点做理性分析，生理上就接收不了
- **「我早就说过」** → 赢了道理，输掉他下次主动告诉你成绩的意愿
- **拿别人比** → 他从此把"学习"和"我不如人"绑定，这个绑定很难解

**此刻你做的三件事**
1. **第一句只接情绪，不碰卷子。**「看你这表情，考得不理想吧。」然后停。**先不评价、先不分析、先不给方案。**
2. **48 小时后再谈。**等他情绪平了，也等你自己的失望退了。那时谈的才是事，不是情绪。
3. **只挑一个可改的点。**不是三个、不是五个。一个能在这周就改的具体动作（比如"读题时把关键词划出来"），比全面清算有用十倍。

**此刻你不能做的**
- 不要说「这次就算了，下次努力」——这是敷衍，他能听出来
- 不要当晚把卷子摊开逐题过——那是审讯的姿态
- 不要把分数和爱挂钩，哪怕开玩笑（"考这么差，妈妈不喜欢你了"）

**根在事前**
建立一个家庭习惯：**考完先不谈分数，先问"哪道题最可惜"。** 这个问法把注意力从"你考了多少"移到"哪里可以更好"，而这个习惯要在考好的时候就建立，不能在考砸的时候才开始。
